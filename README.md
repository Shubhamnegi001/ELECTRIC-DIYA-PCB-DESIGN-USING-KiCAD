# Electronic Diya (PCB Design in KiCad)

## Overview
This project is a PCB design of an Electronic Diya created using KiCad.  
The design includes schematic capture, component placement, and routing.  
The goal was to create a simple, low-cost, and reliable circuit for decorative electronic diyas.

## Features
- Schematic design in KiCad  
- PCB layout with proper routing  
- Low-cost and efficient design  

## Tools Used
- KiCad (PCB Design)  
- Basic Electronics Components
